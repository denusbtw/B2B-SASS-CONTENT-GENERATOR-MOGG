# Animation capabilities

CARTOON_2D renders an original geometric two-actor scene at 360×640 and 24 fps. Speakers alternate by caption cue. Mouth changes follow cue time and the first actor waves. The scene uses simple layered shapes and an original room background. Audio uses timing tones. Final art direction, rigs, phoneme alignment, a second background, camera edits and an asset catalog await further implementation and owner references. Demo shapes and source footage were created procedurally for this repository.
